# 우당탕 힘 실험실

초등학교 3학년 과학 「힘과 우리 생활」을 바탕으로 한 **가로형 태블릿·전자칠판·웹앱** 탐구 게임입니다. 미션마다 **예상 → 직접 조작·비교 → 의뢰(2단계)** 순서로 진행하며, 학생이 예상하고 비교한 기록으로 다섯 구역의 전원을 복구합니다. 기존 MVP의 네 실험에 배운 내용을 다시 쓰는 마지막 코어 운반 작전을 연결했습니다.

각 구역에 들어가기 전 코기 콩이와 첫 생각을 고릅니다. 이 선택은 실험 순서나 첫 설정에 반영되는 진짜 예상입니다. 결과가 나오는 순간 ‘내 예상’ 칩이 날아와 결과 옆에 놓이고, 결과 창과 결과 화면에도 **내 예상 → 실제 결과 → 같았어/달랐어**가 함께 나옵니다. 예상과 다른 결과를 틀렸다고 표시하지 않습니다. 실험 뒤에는 자기 기록을 확인해 두 질문에 답합니다. 미션 도중 진행 항목이 보이며, 결과 화면의 선택형 도전 과제는 반복 횟수가 아니라 서로 다른 조건의 비교 기록으로 얻습니다.

주요 화면 기준은 태블릿 1024×768·1280×800, 전자칠판 1920×1080입니다. 세로 화면에서는 가로 회전/창 확장 안내를 표시하며 진행 상태는 유지합니다. 높이가 작은 가로 창에서는 세로 스크롤이 필요할 수 있습니다.

마을에서는 열린 건물의 문에 닿으면 별도 입장 버튼 없이 실험으로 이동합니다. 건물 이름을 누르면 문까지 자동으로 걸어가며, 방향키·WASD·화면 방향판으로 직접 걸어갈 수도 있습니다. 키 두 개로 대각선 이동이 가능하고, 한글 입력 상태에서도 WASD가 동작합니다. 화면 방향판은 누른 채 다른 화살표로 손가락을 옮겨 방향을 바꿀 수 있습니다. 잠긴 문은 이전 실험 완료 조건을 유지하며, 실험에서 돌아오면 문 바깥에 서므로 즉시 재입장되지 않습니다. 도토리 박사 대화와 가까운 문 수동 입장은 행동 버튼 또는 Enter로도 할 수 있습니다.

## 실행과 확인

```bash
npm install
npm run dev
npm test
npm run build
```

개발 서버 주소를 브라우저에서 엽니다. `npm run build`는 정적 배포 파일을 `dist/`에 만듭니다. 별도 백엔드나 로그인이 필요 없으며, 진행 기록은 현재 브라우저의 `localStorage`에 자동 저장됩니다. 기존 MVP 저장 키 `udangtang-force-lab-save-v1`을 유지하므로 네 실험을 끝냈던 학생은 마지막 미션으로 이어갈 수 있습니다.

설정 → **관리자 해금 → 전체 화면 한꺼번에 해금**에서 구현된 다섯 실험과 결과 화면을 미리 볼 수 있습니다. 미리보기 조작은 학생 완료 기록에 반영되지 않습니다. 해금은 현재 탭에서만 유지되고 새로고침하면 종료됩니다. 이 메뉴는 교사용 미리보기 기능이며 암호 인증 기능은 없습니다.

설정에는 학생 탐구 가이드·교사 운영 가이드·교육과정 연결·정보와 출처가 있습니다. 효과음 켜기/끄기와 음량을 조절할 수 있고, 기록 초기화에는 확인 화면이 있습니다. 음량은 기존 저장에 값이 없으면 30%로 복원됩니다. **기획·제작은 옐샘**입니다.

설정의 **선생님 도구 · 정보** 안에 **의뢰 레벨 필수/선택** 버튼이 있습니다. 기본은 ‘필수’이며, 물자 배송소·균형 다리·재료 보급소·운반 공방은 1단계 실험에 더해 2단계 의뢰까지 마쳐야 미션을 끝낼 수 있습니다. 눌러서 ‘선택’으로 바꾸면 실험만 마쳐도 미션을 끝낼 수 있고, 의뢰는 계속 열려 있어 원하는 학생은 해 볼 수 있습니다. 이 선택은 `save.teacherOptions.requests`로 저장되어 새로고침 뒤에도 유지됩니다. 중앙 코어에는 별도 의뢰가 없어 이 버튼의 영향을 받지 않습니다.

지도의 건물 이름표에 붙은 **별 3칸**은 미션마다(**미션 완료 · 2단계 의뢰 · 도전 과제**)을 합한 값입니다. 별은 따로 저장하지 않고 저장 기록에서 매번 계산하며, 속도·탭 수·정답률은 보지 않습니다. 두 번째 칸은 배송소는 빵집 주문 3장, 균형 다리는 2라운드, 재료 보급소는 2라운드, 운반 공방은 화물 3개를 모두 마친 경우이고, 중앙 코어는 의뢰 대신 ‘같은 힘 비교 발견’(같은 힘에서 한 길은 멈추고 다른 길은 도착한 기록)입니다. 세 번째 칸은 그 미션의 도전 과제를 끝낸 경우입니다. 교사가 의뢰를 ‘선택’으로 바꾸면 아직 받지 않은 의뢰 별은 흐린 ‘꺼짐’으로 표시되고 합계의 최대치에서 빠지지만(모두 안 받았다면 15 → 11), 이미 받은 별은 그대로 셉니다. 별은 마을 건물 이름표, 미션 결과 창, 결과 화면의 미션 카드에도 표시됩니다.

저장은 **origin(프로토콜·호스트·포트)**별로 분리됩니다. `localhost:5173`과 `127.0.0.1:5173`, 개발 주소와 배포 주소, 서로 다른 브라우저 사이에는 기록이 공유되지 않습니다. 학생 이름·학번은 수집하지 않고 실험 기록을 서버로 보내지 않습니다. 공용 기기를 넘기기 전에는 기록 초기화를 사용하세요.

## 오프라인과 배포 조건

현재 자산 경로는 **도메인의 루트(`/`) 배포**를 기준으로 합니다. `dist/` 내용 전체를 HTTPS 정적 호스팅에 올리는 구성입니다. `/project/` 같은 하위 경로 배포는 지원을 검증하지 않았으며, Vite의 base만 바꾸면 기존 절대 자산 경로가 함께 바뀌지 않습니다.

`npm run build`는 `scripts/offline-plugin.mjs`를 통해 `dist/sw.js`를 생성합니다. 배포용 빌드에서만 서비스워커를 등록하고, 다섯 미션의 JS·CSS·이미지·효과음·코어 GLB 두 개를 캐시합니다. 첫 접속에는 인터넷이 필요하고, 화면에 따로 준비 상태를 표시하지는 않으므로 수업 전에 한 번 열어 둔 화면만 오프라인에서 열린다고 보면 됩니다. 개발 서버에서는 오프라인 캐시를 등록하지 않습니다.

캐시는 이 앱과 현재 배포 scope의 접두사로 구분하고, 새 버전이 활성화될 때 해당 scope의 이전 버전만 정리합니다. 진행 중인 탭을 새 코드로 강제 교체하지 않으므로, 새 버전을 배포한 뒤에는 열린 실험실 탭을 모두 닫고 다시 엽니다. 브라우저의 사이트 데이터 삭제·저장공간 회수 시 캐시도 없어집니다. 학교망 동시 접속과 실제 태블릿의 오프라인 수업은 별도 검증이 필요합니다.

로컬 배포용 확인은 `npm run build` 후 `npm run preview`에서 할 수 있습니다. 개발 서버와 다른 포트를 사용하므로 기록이 분리됩니다.

issamGPT AI Mart는 공식 가이드에서 외부 링크 주소·서비스명·소개·파일을 등록하는 방식을 안내합니다. 이 프로젝트에서는 등록 방식만 확인했으며 **실제 게시·업로드·약관 동의를 하지 않았습니다**. [공식 가이드 39쪽](https://sblog.i-scream.co.kr/datafiles/ssamblog/211765/202604160313248001.pdf)을 참고하세요. 플랫폼 운영사와 이 앱의 제작자·저작권자를 동일하게 간주하지 않습니다.

## 학습 목표

초등 3학년 과학 「힘과 우리 생활」 성취기준 [4과01-01~04]에 맞춰 미션마다 하나씩 겨냥합니다.

- **물자 배송소** — [4과01-01] 같은 힘으로 밀고 당길 때 물체의 무게·개수에 따라 움직임이 어떻게 달라지는지 관찰하고 비교한다.
- **균형 다리** — [4과01-02] 두 물체의 자리를 바꿔 보며 수평잡기의 조건을 예상하고 확인한다.
- **재료 보급소** — [4과01-03] 저울로 물체의 무게를 재어 비교하고 숫자를 바르게 읽는다.
- **운반 공방** — [4과01-04] 지레와 빗면 같은 도구를 쓰면 필요한 힘이 달라지는 것을 비교하고 생활 속 도구와 연결한다.
- **중앙 코어** — [4과01-01~04] 앞의 네 미션에서 배운 내용을 한꺼번에 써서 같은 힘으로 코어를 운반한다.

## 배포

Cloudflare Workers 정적 에셋으로 배포합니다. 설정은 `wrangler.jsonc`에 있습니다.

```bash
npm run build && npx wrangler deploy
```

주소: https://udangtang-force-lab.yelsam.workers.dev

`.gitignore`에 `*.mp4`가 있어 인트로·엔딩 영상(`public/assets/story/*.mp4`, `concepts/*.mp4`)은 git 저장소에 없습니다. 그러나 wrangler는 git이 아니라 빌드된 `dist/` 폴더를 직접 올리므로, 로컬에 영상 파일이 있는 상태에서 빌드·배포하면 영상도 함께 배포됩니다. 다른 컴퓨터에서 배포하려면 영상 파일을 먼저 `public/assets/`에 복사해 두세요.

`references/`, `doc/`, `_unused/`는 `.gitignore`로 제외되어 저장소에는 없습니다(이 문서의 `doc/` 링크는 작업 PC에서만 열립니다).

| 복구 완료 | 밝아진 마을 그림과 점등식, 짧은 발견 카드, 자세한 탐구 기록과 미션별 개념 영상(선택) | — |

배송소·공방·코어에는 힘의 크기를 보여 주는 화살표가 있습니다. 화살표 길이는 게임의 힘 단계이며 손가락 압력을 잰 값이 아닙니다. 마을로 돌아오면 새로 끝낸 건물의 창문이 차례로 켜지고 빛이 길을 따라 중앙 코어로 흐르며, 완료한 건물의 불은 계속 켜져 있고 어둑한 안개는 완료 수만큼 걷힙니다. 이야기 영상이 끝나면 검은 화면 대신 마지막 장면 그림을 보여 줍니다.

태블릿을 쓰는 이유는 정답을 터치하는 데 있지 않습니다. 같은 힘에서 조건 하나를 바꿀 때 움직임이 즉시 달라지고, 예상과 실제 기록을 비교하며 다시 시도할 수 있습니다. 2단계 의뢰는 틀려도 벌점이 없고 흔적이 남아 다시 도전하며, 같은 자리에서 두 번 틀리면 단서가 한 단계 구체적으로 바뀝니다. 마지막 미션은 이전 실험의 영점·힘의 방향·빗면 개념을 새로운 운반 문제에 적용하도록 구성했습니다. 게임의 힘 세기는 비교를 위한 단계이며 실제 물리 단위나 정밀 시뮬레이션 수치가 아닙니다.

## 내 실험 기록으로 답하기

각 미션의 실험(필수 의뢰 포함)을 마치면 실제 관찰 기록으로 조건·원리를 확인하고 새 상황에 답하는 **필수 문제 두 개**가 나옵니다. 문제를 다 풀어야 미션이 완료되고 별·도구 카드·다음 미션이 열립니다. 정답 위치는 질문마다 다르고, 오답이면 이유와 단서를 보여 주며 다시 고를 수 있습니다. 최초 선택·마지막 선택·시도 횟수를 따로 저장하므로 ‘활동 완료’와 ‘처음부터 이해함’을 같은 것으로 보지 않습니다.

**저장 정책(2026-10-20)**: 실험은 끝났지만 문제가 남은 상태는 `pendingStage`로 따로 저장합니다. 새로고침·재접속 뒤 그 미션에 들어오면 문제 창부터 다시 열립니다. 저장 버전은 1 그대로이고 새 필드는 없어도 되는 항목이라, 이미 완료된 기존 기록은 취소하지 않습니다. 완료·별·도구 카드는 저장 기록에서 계산하므로 중복 클릭·새로고침으로 두 번 지급되지 않습니다. 배송소·균형 다리 실험 기록은 최대 20개지만 종류별 첫 기록(필수 비교 근거)은 지우지 않고 최근 기록으로 나머지를 채웁니다.

공방에는 같은 도구에서 관측한 힘과 이동 거리의 비교 막대를 함께 표시합니다. 실제 물리 단위나 손가락 압력을 측정한 값은 아닙니다. 선택형 답변의 정오만으로 이해를 확정하지 않고 교사가 학생의 말하기와 실제 도구 활동을 함께 확인합니다.

## 남은 범위

원안의 15페이지를 모두 구현한 상태는 아닙니다. 별도 3D 창고, 세 물체 추론, 용수철저울, 3인칭 슈트 장면은 미구현입니다. 생활 도구는 그림 카드를 고르는 기록까지 구현했고, 도구를 직접 탐색하는 장면은 없습니다. 현재 마지막 미션과 점등식은 기존 탐구를 연결하는 통합 미션입니다.

[2026-10-16 기획안](doc/reviews/ENGAGEMENT_PLAN_20261016.md) 가운데 아래는 **아직 구현하지 않았습니다**.

- 3단계: 코어 최종 구출 작전(앞 네 미션의 도구를 다시 쓰는 자유 순서 도전), 배송소 막힌 골목 퍼즐, 각 미션의 L3 선택 도전
- 마을 광장의 의뢰 게시판과 의뢰인 NPC, 마을 복구 2~3단계(NPC 등장·장식)
- 도구 카드와 도구 가방
- 실험 뒤에 여는 Remotion 개념 클립 5개

기획안의 플레이 시간(기본 30~40분)은 **코드 기반 추정**이며, 실제 학생이 플레이한 시간은 아직 측정하지 않았습니다. 실제 학교 태블릿·학교망 동시 접속 검증과 교실 수업을 통한 학습효과 확인도 별도로 필요합니다.
