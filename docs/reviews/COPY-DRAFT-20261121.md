## B15 — 단원 완료 버튼이 왜 안 눌리는지

**지금 상태(다시 확인)**: 다섯 버튼 모두 조건이 안 되면 `disabled`일 뿐, 이유 문장이 없다. 각 화면 위쪽의 진행 표시(`missionProgressMarkup`, 균형 다리는 목표 칩)가 단계를 보여 주긴 하지만 버튼과 이어져 있지 않다.

**자리와 E-1**: 완료 버튼은 각 화면 아래 `.experiment-footer`에 피드백 줄(`#…-feedback`, `role="status"`)과 함께 있다. 「▶ 자동으로 보기」 버튼은 같은 줄이 아니라 위쪽에 있다(`cargo.ts:56`, `balance.ts:87`, `scale.ts:73`, `workshop.ts:51`). 하지만 피드백 줄은 자동 보기 중에도 문장이 바뀌는 줄이고(예: `cargo.ts:490`), 완료 버튼 상태도 자동 경로와 같은 코드가 정한다(`cargo.ts:235`, `balance.ts:193`, `scale.ts:266`, `workshop.ts:279`). 그래서 배송소·균형 다리·보급소·공방 줄은 **적용 전에 사용자 E-1 확인이 필요**하다(AGENTS.md E-1). 중앙 코어는 자동 보기가 없어(E-1) E-1 대상이 아니다.
