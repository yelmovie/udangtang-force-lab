## 남은 제한

- 실제 태블릿 터치, OS 포인터 캡처/멀티터치, iPad Safari, 한글 키보드·가상 키보드 없음. 합성 PointerEvent 검사를 실기기 검사로 보지 않는다.
- 정상 WebGL 렌더링과 실패 주입을 구분했다. 태블릿 GPU별 장시간 메모리/리소스 사용은 측정하지 않았다. 앞선 클라우드 브라우저의 WebGL 비활성화를 모든 태블릿의 결함으로 일반화하지 않는다.
- 모듈 다운로드 실패 자체를 주입하는 검사는 미실시. WebGL 생성 실패·자산 실패·context lost는 실행 검사했다.
- 미션 3의 개별 의뢰 측정값은 기존 설계상 방문 세션 안에 보관된다. 회전에는 보존되지만 페이지 새로고침/재진입 시 측정표는 초기화된다. 완료 상태·의뢰 통과·별·카드는 보존되며, 완료한 미션을 재측정해야 저장되는 것은 아니다. 이번에는 저장 형식을 변경하지 않았다.
- 공방 2D 대체 실험은 추가하지 않았다. 필요하면 동일한 힘 비교·의뢰 조건을 갖는 별도 작업으로 다룰 수 있다.
