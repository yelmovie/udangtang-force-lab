## 공식 요청별 처리
1. 미션2 첫 물체 이후 오른쪽 접시 클릭 영역 겹침: 공통 탭 힌트의 position:relative가 접시의 절대 위치를 덮던 원인 수정. 균형 다리 전용 선택자에서 absolute를 유지하고 좌우 반대쪽 위치를 auto로 고정했다. 양쪽 힌트가 생긴 뒤에도 실제 접시 중심이 해당 버튼에 적중하는 회귀 검사를 추가했다.
2. 힘을 덜 드는 도구 → 힘이 덜 드는 도구: 개념 영상 제목 수정.
3. 길고 완만하게에서 → 길고 완만한 빗면에서: 설계 이름을 명사형으로 바꿔 학습 정리 문장과 기록에 함께 적용. 짧고 가파른 빗면도 같은 방식으로 수정하고 기대값 검사를 갱신했다.
4. 수평잡기 → 수평 잡기: 미션 개념과 교육과정 설명 수정.
5. 전기 전원이 모두 나갔어 → 전기가 모두 나갔어: 프롤로그 대사 수정.
6. 잠긴 건물 안내 먼저 먼저 중복: 대체 미션 이름에서 중복된 먼저 제거.
7. 지정 나눔스퀘어네오: UI/본문/SVG 간판에 적용. NAVER 공식 정적 WOFF 400/700/800/900을 자체 호스팅하고 공식 SIL OFL 1.1 전문과 출처 링크를 포함했다. preload와 오프라인 최초 캐시도 WOFF를 지원하도록 변경했다.

## 글꼴 확인
- 공식 배포: https://hangeul.naver.com/font
- 공식 선언: https://hangeul.pstatic.net/hangeul_static/css/nanum-square-neo.css
- 라이선스: https://help.naver.com/service/30016/contents/18088?osType=PC&lang=ko
- 최초 확인한 공식 Variable.woff는 로컬 HTTP 200 및 바이트 일치에도 Chrome FontFace.load에서 NetworkError가 발생했다. 따라서 이 파일은 배포 자산에 넣지 않고 정상 로딩을 실측한 공식 정적 파일4종으로 대체했다. 글꼴 바이너리는 수정하지 않았고 파일명만 로컬 이름으로 바꿨다.
- 브라우저 fixture에서 네 굵기 모두 document.fonts.load/check 통과. CSS에 가족명만 표기한 것을 완료 근거로 삼지 않았다.

- fixture는 신규/준비 상태의 로컬 모듈 검사다. 전체 학생 플레이 완료로 해석하지 않는다. 실제 iPad Safari/Android Chrome 터치·회전·백그라운드 복귀·오프라인 및 Mac은 미검증.
- graphify 실행 파일이 이 Windows 환경에 없어 그래프 갱신은 실행하지 못했다.

## 배포 보류 이유
Git 사본에는 public/assets/story의 intro/final 포스터만 있고 원본 mp4가 없다. concepts는 webm/포스터가 있지만 mp4는 없다. 저장소 지침대로 이 dist를 운영에 배포하면 기존 영상이 사라질 수 있어 배포하지 않았다. SSD 원본 영상을 복원·검증한 컴퓨터에서 다시 빌드한 뒤 배포해야 한다.
