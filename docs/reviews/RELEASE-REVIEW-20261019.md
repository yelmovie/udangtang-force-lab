## FAIL (3건)

### 1. 배송소 '조금 더 실험할래요' 뒤 조작 잠김 + 탭 대안 없음 (B19)
1. 문제: 완료 팝업에서 '조금 더 실험할래요'를 누르면 팝업만 닫히고 캐릭터 손잡이·힘 버튼이 비활성, 부품 고르기도 숨겨져 더 실험할 수 없다. 1단계에서도 실험 시작은 드래그(또는 키보드 Enter)만 되고, 탭만 하면 "오른쪽 표시까지 옮겨야 출발해요" 안내만 나온다.
2. 우선순위: P1(진행은 막지 않지만 재실험 불가)
3. 화면: 미션 1 물자 배송소, 2단계 배달 완료 후 / 재입장 직후
4. 재현: 미션 1 완료 → 완료 팝업 '조금 더 실험할래요' (또는 지도에서 재입장 → 자동으로 뜨는 같은 팝업)
5. 예상: 밀기·당기기·부품·힘을 바꿔 다시 실험 가능
6. 실제: `.cargo-worker-grip` disabled=true, `[data-force]` 3개 모두 disabled, `.cargo-inventory` 숨김
7. 근거: 브라우저 관찰. 교실 언어로: "더 해 보고 싶은 아이가 버튼을 눌러도 아무것도 안 움직인다"
