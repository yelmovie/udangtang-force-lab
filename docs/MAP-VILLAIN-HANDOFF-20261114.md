## 외형과 등장

**바퀴잠금 봇 / 오렌지 안전모, 낮은 쐐기 몸통, 큼직한 클램프.** 스테이지 완료 기록 후 지도에 돌아올 때 해당 장소 옆에 등장한다. 기존 주인공·동료·건물의 스타일을 유지하고, 악당과 소품의 접점이 글 없이도 읽히게 그린다. 아래 소품 동작은 지도 위 짧은 장난 컷이다. 활동 화면이나 기존 학습 데이터에는 손대지 않는다.

기존 모듈부터 대조. 실제 수레 바퀴나 균형 다리의 시각적 모티프만 가져온다.

## 스테이지마다 바뀌는 소품·자세·대사

장소명은 기획상의 연결 기준이다. 활성 버전의 스테이지 ID와 이름을 대조한 뒤 키를 정한다. 선택 구역은 실제 별도 완료 이벤트가 있을 때만 추가한다.

| 장소 | 악당 스프라이트 동작 | 첫 등장 또는 접근 대사 예시 |
|---|---|---|
| 물자 배송소 | 바퀴를 집게로 꾹 잠그기 | “바퀴 한 번 잠그면 못 가지!” |
| 균형 다리 | 한쪽 추를 발끝으로 밀기 | “이쪽을 조금만 눌러 볼까?” |
| 재료 보급소 | 저울받침을 들썩이기 | “저울이 왜 자꾸 덜컹대지?” |
| 운반 공방 | 빗면 아래 받침을 꺼내 숨기기 | “받침이 어디 갔을까?” |
| 중앙 코어 | 운반대에 몸으로 쐐기 박기 | “코어 운반은 여기서 끝!” |

상황 대사 예시:

- 접근: “바퀴 딱 잡았다!” / “못 지나가게 꽉 잠가야지!”
- 1·2타: “앗, 집게가 풀렸어!” / “스프링이 덜컥!”
- 퇴장: “나사까지 다 풀리잖아!” / “다음 수레를 찾아야겠어!”

스테이지 고유 문장을 우선하고, 상황 대사는 연속 반복 없이 고른다. 주인공·보조 캐릭터의 주민 대화와 겹칠 때는 악당 말풍선을 생략한다.

## 세 번의 타격과 접촉 피격

| 사건 | 이 프로젝트의 표현 |
|---|---|
| 1타 · 짧은 명중 | 스프링이 짧게 눌렸다 펴지며 톡 |
| 2타 · 더 큰 반동 | 청록 와셔가 두 조각 튐 |
| 3타 · 마무리와 퇴장 | 클램프가 툭 벌어지고 나사 두세 개를 흘리며 굴러 퇴장 |
| 주인공 접촉 | 주인공은 한쪽 발을 구르며 중심을 다시 잡음 |
| 보조 캐릭터 접촉 | 동료는 몸을 낮추고 위로 통 튐 |
| 악당의 접촉 공격 동작 | 스프링을 꾹 압축한 뒤 클램프를 앞으로 ‘딱’. 클램프 끝이 닿는 프레임에서만 피격 표시. |
| 타격·퇴장 효과음의 차이 | 톡 → 덜컹 → 와르르 |
| 접촉 효과음 모티프 | 둔탁한 스프링 ‘퉁’ |

세 타격은 같은 공격 입력이다. 가까이 있는 상태에서 한 입력이 한 타로 계산된다. 접촉 피격은 닿은 쪽만 재생하고 공격 카운트와 학습 진행에는 영향을 주지 않는 것을 권장한다. 소리를 꺼도 표정·자세·게이지로 읽혀야 한다.

## 방향과 시선

[공통 방향 규칙](../../_shared/MAP-VILLAINS-HANDOFF-20261114.md#방향시선공격-자세)을 적용한다. 클램프가 주인공 쪽에서 닫히도록 손 위치를 좌우로 맞춘다. 바퀴를 잠근 장난 자세에서는 수레를 고정하고, 몸과 시선만 주인공 쪽으로 돌린다.

## 제작하고 적용할 순서

1. 기존 진입점 확인: [src/data.ts](../src/data.ts) · [src/main.ts](../src/main.ts) · [src/map-villains.js](../src/map-villains.js). 활성 지도와 완료 상태, 실제 주인공/보조 지도 원본·이름, 기존 악당/스프라이트·대사·저장부터 확인한다.
2. 기본 악당 한 장, 위 표의 장소별 소품 동작 스트립, 공통 이동/접촉 전조/피격/퇴장 프레임을 제작한다. 주인공·보조 피격은 각각 4~6프레임. 소품이나 배경을 몸통 시트에 같이 구워 넣기 전에 지도 크기에서 알아볼 수 있는지 확인한다.
3. 별도 승인된 구현 단계에서 완료된 장소 좌표에 악당을 붙이고, 기존 HUD 근처에서 공격·타격·피격·퇴장만 연결한다. 기존 이동/화면 전환/복구 상태와 학습 완료/다음 장소 해금은 보존한다.
4. 완료 전/후, 정확한 3타, 두 아군의 개별 접촉, 퇴장 및 재진입, 빠른 연타, 무음·모션 감소·태블릿을 확인한다. 가장 작은 정상 지도 표시 크기에서 소품과 방해 동작이 구분되는지 본다.

완료된 것: 정적 이미지 합성과 계획. 남은 것: 기존 시트/캐릭터 일치 확인, 프레임 제작, 대사 최종화, 구현 및 테스트. 06 물의 상태 변화는 참고 전용.
