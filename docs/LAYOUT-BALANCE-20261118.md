## 2. 중복 조작 버튼 전수 점검

방법: 홈 → 지도 → 미션 카드 → 다섯 미션 첫 화면을 저장값을 심어 열고 보이는 조작 요소(글자·aria-label·위치)를 JS로 뽑았다(`before/report.json`). 팝업·설정·의뢰 편지·문제 풀기·도구 가방·카드 보관함은 코드에서 버튼과 핸들러를 대조했다.

| # | 화면 | 중복 | 처리 |
|---|---|---|---|
| D1 | 지도 | 왼쪽 위 「작전 지도로」 홈 버튼이 지도 화면에서는 아무 일도 하지 않음(`viewPage !== 'map'`일 때만 이동) | 지도 화면에서만 홈 버튼을 그리지 않음. 뒤로(타이틀)는 같은 자리 유지 |
| D2 | 미션 완료 팝업(5개 미션 공통 `watchFinish`) | 위 ×와 「조금 더 실험할래요」가 똑같이 닫기만 함 | × 숨김 |
| D3 | 물자 배송소 결과 팝업 | ×와 「계속 실험하기/더 실험해 보기」가 같은 닫기 | × 숨김 |
| D4 | 균형 다리 결과 팝업 | ×와 「계속 실험하기」(`#balance-popup-close`)가 같은 닫기 | × 숨김 |
| D5 | 재료 보급소 결과 팝업 | ×와 「계속 실험하기」가 같은 닫기(이 버튼이 있을 때만) | 그때만 × 숨김. 「다음 의뢰」「비교 기록 저장」만 있는 팝업은 × 유지 |
| D6 | 운반 공방 기록 팝업 | ×와 「계속 실험하기/다음 화물 →」가 같은 닫기 | × 숨김 |
| D7 | 의뢰 편지(배송소·보급소·공방 등) | ×와 「나중에 볼게요」가 같은 닫기 | × 숨김 |
| D8 | 설정 | 위 ×와 아래 「닫기」가 같은 닫기 | 아래 「닫기」 숨김(도구 가방·카드 보관함·다른 설정 화면과 같은 위 × 하나) |
| D9 | 문제 풀기(결과 화면) | 머리의 ×(aria-label 「결과로 돌아가기」)와 아래 「결과로 돌아가기」가 같은 동작 | × 제거(Tab 순환이 보이는 버튼만 돌도록 마크업에서 뺌) |

모든 팝업은 Esc로도 닫히고(dialog 기본 동작·문제 풀기는 기존 Esc 처리), 핸들러는 그대로라 진행 경로는 바뀌지 않는다.
