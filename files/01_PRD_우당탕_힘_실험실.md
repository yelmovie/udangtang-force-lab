# 우당탕 힘 실험실 — PRD

## 1. 프로젝트 개요
- 콘텐츠명: 우당탕 힘 실험실
- 대상: 초등학교 3학년 1학기
- 단원: 과학 「힘과 우리 생활」
- 형식: 태블릿 가로형 웹앱 / PC 웹 / 전자칠판
- 핵심 구조: 5 Mission × 2 Screen = 10개 핵심 학습 화면
- 전체 페이지: 15페이지
- 3D 핵심 화면: 4, 9, 12페이지
- Repository: `udangtang-force-lab`
- GitHub Description: `An interactive Grade 3 science game where students explore forces, balance, weight measurement, levers, and inclined planes through hands-on experiments and problem-solving.`

## 2. 제품 목표
학생이 단순히 문제를 푸는 것이 아니라,
**예상 → 조작 → 관찰 → 비교 → 수정 → 적용**의 탐구 순환을 경험하도록 설계한다.

학생은 고장 난 힘 실험실의 예비 동력 코어를 중앙 장치까지 운반하기 위해
밀기·당기기, 수평잡기, 저울 측정, 지레·빗면을 직접 실험하고
그 결과를 이용해 실험실을 복구한다.

## 3. 핵심 교육과정
### [4과01-01]
물체를 밀거나 당길 때 나타나는 변화를 관찰하고,
무거운 물체와 가벼운 물체를 움직일 때 드는 힘의 크기를 비교한다.

### [4과01-02]
수평잡기 활동을 이용하여 물체의 무게를 비교한다.

### [4과01-03]
물체의 무게를 정확하게 비교하기 위해 저울이 필요함을 알고,
저울을 바르게 사용한다.

### [4과01-04]
지레와 빗면을 이용할 때 드는 힘의 크기가 달라짐을 관찰하고,
생활 속에서 이러한 도구가 쓰이는 예를 조사한다.

## 4. 교육과정 범위 제한
다음은 가르치지 않는다.
- 뉴턴(N) 단위 계산
- 토크 및 힘×거리 공식
- 지레의 기계적 이득 계산
- 고학년 수준의 질량/무게 엄밀 구분

대신 다음을 경험하게 한다.
- 무게에 따른 힘의 차이
- 수평잡기를 이용한 비교
- 정확한 측정을 위한 저울 사용
- 영점, 흔들림, 눈높이 등 올바른 측정 절차
- 지레·빗면 사용 전후의 정성적 힘 비교

## 5. 핵심 게임 루프
`QUEST → ACTION → REACTION → THINK → ADJUST → RETRY → EVIDENCE → WORLD CHANGE`

최종 흐름:
`FINAL REPORT → FINAL MISSION → FINAL MOVIE → CERTIFICATE`

## 6. 메인 퀘스트
힘 실험실의 중앙 동력 장치가 멈췄다.
예비 동력 코어를 중앙 장치까지 옮기려면
다섯 구역의 문제를 과학적 실험으로 해결해야 한다.

## 7. Mission 구성
1. 움직임의 단서 — 밀기·당기기와 무게에 따른 힘 비교
2. 균형의 암호 — 수평잡기와 무게 비교
3. 정확한 무게 — 전자저울·용수철저울 사용
4. 힘을 아끼는 장치 — 지레·빗면 구성과 생활 도구 활용
5. 핵심 화물 운반 — 개념 통합 적용

## 8. Evidence 5종
1. 힘 비교 관찰 기록
2. 균형 비교 데이터
3. 정확 측정 기록
4. 도구 활용 설계도
5. 최종 운반 계획서

## 9. 캐릭터 역할
- 학생 탐구자: 플레이어 대리자
- 코기 실험 파트너: 질문·힌트·퀘스트 안내
- 다람쥐 연구 기록관: 실험 기록·Evidence·Final Report

무의미한 로봇 NPC는 사용하지 않는다.
